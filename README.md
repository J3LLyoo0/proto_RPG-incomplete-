# Python RPG Prototype

A simple console-based RPG prototype developed using Python.  
The project was created to explore basic game logic, player interactions, and decision-making through a text-based RPG format.

## Features

- Text-based player interactions
- Basic RPG decision-making
- Conditional game logic
- Loop-based gameplay flow
- Use of Python lists to manage game data

## Technologies Used

- Python

## Purpose

This project helped me develop a better understanding of Python programming and how basic RPG systems and player interactions can be structured within a console application.
